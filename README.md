# 興中國小國內出差旅費試算工具

[直接開啟工具](https://ccwforwork1115-ai.github.io/travel-expense-tool/)

## 使用方式

- 起點預設興中國小，可自行修改。
- 輸入目的地關鍵字，即顯示個人與內建常用地點；支援部分名稱及台／臺比對，點選即可填入。
- 內建 229 個地點，包含本次提供的 13 個中心、場館、大學與鄉公所，其餘來源為「特教中心提供-交通費計算114.01.01.xlsx」的國中小、幼兒園與其他單位工作表。
- 起點為興中國小、單一目的地且有表列公里數時，直接套用表內單程及來回里程，不必查詢道路。其他起點、未收錄地點或多站行程，回到道路查詢模式。
- 縣府、創新學院及永在食安大樓單程 20.6、來回 41.2 公里。
- 道路查詢比較候選路線並擇短，非保證全路網最短；多站依序前往，最後一站直接返回起點。
- 地址查不到或定位服務失敗時，提供「用 Google Maps 查詢」按鈕，另開 Google Maps 路線分頁，自動填入起點、目的地及依序停留點。此功能不需 API 金鑰，不會自動帶回 Google 的位置或里程；確認後可修改輸入再試算。
- 報支資料集中列出起點、目的地、公里數與交通費試算；已啟用且有金額的雜費一併顯示。結果區提供填寫與送件提醒；差勤系統入口移至查詢表單上方，先確認待報行程再查公里數。

## 個人常用地點

- 支援自行建立、重新命名與刪除地點群組；使用地點旁的選單分組，並可篩選全部、未分組或指定群組。
- 舊收藏與新加入地點預設未分組；刪除群組會保留地點並移回未分組。群組與分類儲存在目前瀏覽器，重新開啟仍保留。
- 群組操作驗證：`node verify-favorite-groups.cjs`；手機及桌面版面驗證：`node verify-mobile-layout.cjs`。
- 群組篩選採可點選標籤；管理功能集中在彈跳視窗。地點名稱、群組選單與刪除按鈕在同一列，充分利用右側空間。
- 「管理群組」開啟彈跳視窗，可新增、選擇、重新命名或刪除群組。視窗內可搜尋內建地點並直接加入所選群組，無須先計算；已加入項目顯示勾選。
- 點選群組標籤後可按「整組加入行程」，管理視窗也提供加入按鈕。依收藏順序加入目的地，保留既有行程並略過重複地點；使用者確認停留順序後再按計算。驗證：`node verify-group-trip.cjs`。
- 「未分組」僅為篩選分類，不視為群組，無法整組加入行程；只有使用者建立的群組提供此操作。

- 目的地輸入完成離開欄位、點選建議或按下計算時，自動加入個人常用地點；重複、空白及輸入中的文字不加入。
- 「我的常用地點」預設收合，查詢地點會自動加入，地點旁的 × 可刪除；小型「一鍵清除」按鈕確認後清空個人清單，保留內建清單與目前行程；點選填入目前選取的欄位，欄位已滿時新增一站。
- 內建完整清單也預設收合，可展開搜尋。
- 個人清單最多 50 個，儲存在目前瀏覽器的 localStorage。重新開啟會保留，重設行程不會清除；不同裝置不會同步，共用瀏覽器會共用清單，清除網站資料會移除清單。

## 先整理群組，再做多點報支

1. 展開「我的常用地點」，點「管理群組」。
2. 輸入名稱並新增群組；新增後會自動選取。管理既有群組時，使用「選擇群組」選單。
3. 在同一視窗搜尋內建學校或單位，點選地點加入所選群組；已加入項目顯示勾選。這一步不會變更目前行程或觸發計算。
4. 按「將所選群組加入行程」，或關閉視窗、點選群組標籤後按「整組加入行程」。
5. 核對起點與交通方式，用目的地旁的上下箭頭調整停留順序，確認單程／來回與雜費設定，再按「計算旅費」。

整組加入會保留既有目的地、填入空白欄位並略過重複地點；順序依個人清單排列。未分組只是分類，仍可逐一點選地點，但不能整組加入。多點行程依停留順序查詢各段道路，來回行程最後一站直接返回起點，不逐站累計學校來回。

## 雜費設定（特教中心用）

預設不報支，有核准依據再勾選。自動試算不代表核准。

- 不適用：不可報支雜費，全天、半天皆為 0 元。
- 200 元級距：縣外單程未滿 60 公里，或縣內單程 10 公里以上；半天 100 元。
- 400 元級距：縣外單程 60 公里以上（含剛好 60 公里）；半天 200 元。
- 高鐵須依核准類別手動選擇雜費；交通費依實際票價報支。
