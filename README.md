# 興中國小出差旅費試算

[直接開啟工具](https://ccwforwork1115-ai.github.io/travel-expense-tool/)

## 使用方式

- 起點預設興中國小，可自行修改。
- 輸入目的地關鍵字，即顯示個人與內建常用地點；支援部分名稱及台／臺比對，點選即可填入。
- 內建 216 個地點，來源為「特教中心提供-交通費計算114.01.01.xlsx」的國中小、幼兒園與其他單位工作表。
- 起點為興中國小、單一目的地且有表列公里數時，直接套用表內單程及來回里程，不必查詢道路。其他起點、未收錄地點或多站行程，回到道路查詢模式。
- 縣府、創新學院及永在食安大樓單程 20.6、來回 41.2 公里。
- 道路查詢比較候選路線並擇短，非保證全路網最短；多站依序前往，最後一站直接返回起點。
- 報支資料集中列出起點、目的地、公里數與交通費試算；已啟用且有金額的雜費一併顯示。下方提供報支流程及差勤系統連結。

## 個人常用地點

- 目的地輸入完成離開欄位、點選建議或按下計算時，自動加入個人常用地點；重複、空白及輸入中的文字不加入。
- 「我的常用地點」預設收合，可收藏、新增、修改或刪除地點；點選填入目前選取的欄位，欄位已滿時新增一站。
- 內建完整清單也預設收合，可展開搜尋。
- 個人清單最多 50 個，儲存在目前瀏覽器的 localStorage。重新開啟會保留，重設行程不會清除；不同裝置不會同步，共用瀏覽器會共用清單，清除網站資料會移除清單。

## 雜費設定（特教中心用）

預設不報支，有核准依據再勾選。自動試算不代表核准。

- 不適用：不可報支雜費，全天、半天皆為 0 元。
- 200 元級距：縣外單程未滿 60 公里，或縣內單程 10 公里以上；半天 100 元。
- 400 元級距：縣外單程 60 公里以上（含剛好 60 公里）；半天 200 元。
- 高鐵須依核准類別手動選擇雜費；交通費依實際票價報支。

## 網站檔案與維護

首頁 index.html 為單檔工具；出差旅費計算工具.html 為相同功能的另存版本，app.js 保留程式來源。固定里程與常用地點功能不需道路查詢，地圖及其他路線查詢需要網路。

更新程式時需同步 app.js 與兩個 HTML 內嵌程式。固定里程資料位於 suppliedMileage，內建地點位於 suppliedPlaces。匯入里程及地點的 JSON 為資料來源備份。

## 停止訂閱 ChatGPT 後仍可使用

本工具不使用 OpenAI API，也不依賴 ChatGPT 訂閱。停止訂閱不會使工具停用；網站可用性仍取決於 GitHub Pages 與外部地圖、路線服務。

日後仍可請 ChatGPT 或 Codex 協助修改。免費方案的模型、額度及工具權限，以當時方案為準，不保證永遠能直接操作 GitHub；若無法直接更新，也可請其提供修改內容與操作步驟。

## 日後如何修改交通費率

目前汽車每公里 3 元、機車每公里 2 元。費率應在新規定確認並生效後更新。

例如，可提出以下要求：

> 汽車費率改成每公里 4.5 元，請同步更新計算公式、畫面費率文字與 GitHub 網站，機車維持不變。

修改完成後，請確認：
- 計算公式與交通方式選項的費率文字一致。
- 汽車來回 41.2 公里，按每公里 4.5 元計算時為 185 元（四捨五入）。
- 單程、來回及機車計算仍正常。
- 更新的是根目錄的 index.html，並等待 GitHub Pages 部署完成。

也可自行在 GitHub 開啟 index.html，點選編輯，修改汽車費率文字及公式中的汽車倍率，再提交變更。切勿把其他用途的數字 3 一併取代。網站網址不變，使用者重新整理即可取得新版。
